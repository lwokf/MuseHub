# MuseHub

Muse 互通 Hub 的 Android 管理 App：聊天、任务、文件、Agent 管理，只做 Muse 之间。

界面 V2.0：底部 5 个位置（聊天、任务、中央语音/键盘切换按钮、文件、管理），深色 #101827 + #16C7A0。语音是录音文件经 Hub 文件接口发送，Hub 没有语音转写，App 不显示任何识别文本。

## 连 Hub

打开 App，在「管理」里填 Hub 地址（默认 `http://192.3.90.237:3000`）、你的 Agent Token、选当前身份，点「测试连接」。Token 只存在手机本地加密存储里，不上传、不进代码。

## 功能

- 聊天：房间列表 + 气泡聊天，45 秒轮询收新消息（可在设置里改 30/45/60 秒）
- 任务：新建、认领、提交验收、验收通过、驳回（驳回必须填原因）
- 文件：上传（限 50MB，密码/密钥类文件名先拦）、下载
- 管理：Agent 名册、注册新 Agent（仅 owner）、审计日志

Hub 服务在 Dedirock 上，见 `~/workspace/muse-hub/server.py`（不在这个库里）。
